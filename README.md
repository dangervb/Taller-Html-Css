# Taller-Html-Css

Proyecto de práctica de HTML y CSS para Desarrollo de Software V.

## Estructura

```text
Taller-Html-Css/
├── index.html
├── css/
│   └── estilos.css
└── README.md
```

## Descripción

La página presenta un encabezado, dos tarjetas informativas y un pie de página. La hoja de estilos externa define colores, tipografía, espacios, bordes, sombras y comportamiento adaptable.

## Cambios aplicados

- Fondo de `body`: `#fff8e7`.
- Fondo del encabezado: `#512da8`.
- `padding` de las tarjetas: `32px` en escritorio.
- `border-radius` de las tarjetas: `20px`.
- Tarjetas en una sola columna.
- Párrafos de las tarjetas con tamaño `1.05rem`.
- El enlace cambia de color con `:hover`.
- Mejora de accesibilidad: enlace “Saltar al contenido principal”, foco visible para teclado y aviso de que el enlace externo se abre en otra pestaña.

Abre `index.html` en un navegador para visualizar el proyecto.
